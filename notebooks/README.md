# Historical Notebook Archive

Status: Historical

Audience: Researchers and maintainers

Canonical topic: Historical notebook-script location

Last verified: 2026-10-10

These dated scripts and notebooks predate the experiment archive convention.
They remain in place so recorded output paths and parity provenance continue to
resolve. Put all new research under [`experiments/`](../experiments/README.md).

`notebooks/outputs/` is generated local evidence and is ignored by default.
Curated behavior belongs in package code, tests, and canonical documentation,
not in this archive.
